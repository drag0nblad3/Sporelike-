# Sporelike: notes for Claude

An evolution game in Godot 4.5 (GDScript), built for Android first and Windows second. The owner tests only on an Android phone, using the APK from the `playtest` release, so there is no local editor in the loop.

## Code layout rules

- **Keep files small and single-purpose.** One class per file, ideally under about 150 lines. Add a new file rather than growing an existing one into a catch-all, so a change only needs to read the file it touches.
- Build scenes in code. `scenes/main.tscn` is only a root node with `scripts/main.gd`; keep `main.gd` (title screen to `Game`) and `game.gd` (one session) thin wiring layers.
- Folders: `scripts/core` (pure data and rules, like `Genome`, `BodyPlan`), `scripts/creatures` (organisms, colonies and their AI and visuals), `scripts/physics` (`SoftBody` springs, `SoftContact`, `IkChain`), `scripts/world` (arena, food, ecosystem, seaweed), `scripts/ui` (HUD, joystick).
- The multicellular stage runs inside `Game` through `StageTwo` (switch at the stage 1 goal, `ColonyPilot`, `ColonyChoices` for cell picks, feeding style and the final body that ends the stage). Cell effects live in `CellEffects`; bites and regrowth in `ColonyWounds`, `ColonyThreat` (hunters) and `ColonyBites` (rival colonies from `RivalColonies`); abilities in `ColonyAbility`/`ColonyCaster`. Stage 2 surroundings (`ColonyWorld`) follow the colony and change by sea region: `PlantKind` seaweed, `MarineSnow`, `RockField` rocks and vent chimneys, `Carrion` from dead rivals. Each sea has one boss, `ApexKind` (spawned by `ApexHunt`, steered by `ApexBrain`), that anyone may bite (`ColonyBites.attempt(..., any_size)`); killing it drops a feast and adds `ApexKind.PROGRESS_BONUS` progress. Colonies swim at three `Depth` layers (floor, open water, surface; `DepthControl` buttons) and only touch, eat or bite things at their own depth; `CombJelly` hunters dive from the surface. At 40 cells (cap 60) `Shallows` puts a coast to the north (`ShoreLine` slope and tide, `ShoreLook`, `TidePools`); the final body is picked there and the colony hauls out (`ColonyPilot.haul_out`), the opening of the land stage 3 (plan: https://claude.ai/artifact/UhXB3wu2ft6y2sfQ97rf1i). Stage 2 generations last 120 s. Sunlight caustics (`CausticLight`, `CausticShader`) ripple over the stage 2 floor; the shore sand uses `SandShader` and `BeachPebbles`.
- Stage 3 (land only) starts as a feel test: the title's "Test stage 3" opens `AnimalLab` with `LandTerrain`/`LandScatter` on `LandHeight` hills, an `Animal` (`AnimalBody` segment shapes, limbs, head/tail/back parts and patterns rolled by `AnimalRandom`; `AnimalGait` reads slither/creep/hop/scuttle/walk; `AnimalLegs` of `LegStepper` on `IkChain`; drawn by `AnimalLook`, `AnimalNeckLook` (neck and head placement), `AnimalHeadLook`, `AnimalEyeLook`, `AnimalMouthLook`, `AnimalLimbLook`, `AnimalArmLook` and, for a smooth body, `AnimalSkinLook`, from `AnimalParts`; symmetry two-sided/radial; posture crawl, leaning biped or upright biped (segments stacked up from the hips); stance and knees set how legs stand; `AnimalWords` writes the status line; body skin is `AnimalSkinMaterial` (shading, scales/warts/fuzz texture), feathers and quills come from `AnimalCoverings`, and one part can be oversized), `ChaseCamera` and `AnimalLabHud` (joystick plus `LookPad` on the right). The lab's goals are `LandGoals`: `LandFood` carried home to the `LandNest` lays eggs, and `LandLandmarks` (river ford, crag summit, forest heart) unlock `LandUnlocks` part families that the `AnimalEditor` skips until then. `LandGenerations` runs 180 s generations; at the end the nest's eggs become an `EvolveBudget` of customizer rows to change, and the new body hatches at the nest. The lab's Free edit button skips the budget for testing. Customize opens `AnimalEditor` (rows of `AnimalEditRow` over an `AnimalRecipe`, built into a body by `AnimalBuilder`; add a customizer option as a row in `AnimalRecipe.ROWS` plus a line in `AnimalBuilder`). The title screen's "Test stage 2" starts a throwaway game with a random evolved species (`EvolvedSpecies`) straight at the switch, without saving. `ColonyLab` is a sandbox used by CI and the screenshot tour.
- Stage 4 (the village) is `VillageLab`, opened by the title's "Test stage 4" or by founding a village at the end of stage 3 (`LandFamily`: eggs hatch kin that follow the player, the Call button, a prowler; `AnimalLab.village_founded`). The player walks the elder (an `Animal`; `ElderActions` for its bite, building help, aura and Rally) or switches to the `OverheadCamera` and gives broad orders in `VillagePanel` (`VillageHud`; `TouchButton` for buttons that must work beside the joystick). `Village` holds the villagers, food, `VillageJob` counts, `VillageBuildings` (`VillageBuilding` data), flag and alarm; `VillagerBrain` runs each villager; `VillageGrowth` does births and succession; `VillageTraits` turns stage 3 parts into village bonuses; villagers learn by working (`VillageLearning` bars per job; `Discovery` lists what each job can figure out; `DiscoveryPick` is the choice screen; `VillagerGather`, `LandRoots` and `VillageCamp` hold what discoveries add); `VillagePrey`/`PreyBrain`, `VillageRaids`/`RaiderBrain` and `RivalTribe` are the other animals; `VillageRun` scores the run; `VillageEvents` wires the lab; `VillageStatus` writes the status lines. Everyone but the elder is a `CrowdActor` (plain data) moved by `CrowdMotion` and drawn by `LandCrowd`: `CrowdProxies` (three MultiMeshes for the whole crowd) with full `Animal` bodies lent to only the nearest five by `CrowdAvatars`. Keep new land creatures on this path; do not add an `Animal` node per creature. CI covers it with `VillageCheck` (smoke) and `VillageShots` (screenshots).
- Give every class a `class_name` and a `##` doc comment saying what it owns.
- Use explicit types where a value comes from a Dictionary or untyped Array; `:=` on a Variant is a compile error.

## Checking changes

- No Godot binary is available in the Claude environment. Run `gdparse` and `gdlint` from `pip install "gdtoolkit==4.*"` for syntax, then rely on CI.
- CI (`.github/workflows/build.yml`) runs the game headless for 15 game-seconds with `-- --smoke` (2-second generations, mutations auto-picked, the save reloaded once at generation 2) and fails on any `SCRIPT ERROR`. Pull requests stop there. Merges build nothing; a manual run of the workflow (workflow_dispatch, e.g. the GitHub MCP `actions_run_trigger` on `main`) also exports the APK and replaces the `playtest` release. Only start one when Tyler asks for a build. No Windows build is made for now.
- Headless runs never draw, so CI also runs `-- --shot` under xvfb with the real renderer (`scripts/screenshot_tour.gd`): gameplay, a zoomed-out map, a far-away spot (chunk loading), pause menu, population screen and title. Artifact downloads are blocked from the Claude environment, so each shot is also printed to the job log as `shotb64 <name> <base64 jpeg chunk>` lines; decode them to look at UI changes.
- Make full-screen controls with `set_anchors_and_offsets_preset`, not `set_anchors_preset` (that left the pause menu zero-sized).
